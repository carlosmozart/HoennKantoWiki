Seu fluxo de edição

  1. Escolha o conteúdo e a seção na biblioteca.
  2. Edite campos, listas, times ou textos dos guias.
  3. Use Atualizar prévia para conferir o rascunho.
  4. Clique em Salvar no projeto. Uma cópia do arquivo anterior será guardada antes de cada gravação.
  5. Revise as alterações no GitHub Desktop e faça commit/push quando quiser publicar.

Rascunhos são recuperáveis neste navegador. Use “Exportar rascunho” para guardar uma cópia independente.

Para recuperar uma versão, selecione o conteúdo correspondente e use “Importar JSON” com o backup desse arquivo. Confira a prévia e salve.

O editor também cria páginas e modelos de cards, importa imagens e edita textos da interface. As correções da Pokédex ficam separadas dos dados gerados. Para trocar de PC, salve e envie os arquivos pelo Git; rascunhos podem ser exportados.
